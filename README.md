Judul : Analisis Pengaruh Tingkat Partisipasi Angkatan Kerja (TPAK) terhadap Tingkat Pengangguran Terbuka (TPT) di Kabupaten/Kota Sulawesi Tengah
Nama : Siti Fadilah Kirani
Mata Kuliah : Statistika dan Probabilitas
Studi Kasus : Menganalisis pengaruh Tingkat Partisipasi Angkatan Kerja (TPAK) terhadap Tingkat Pengangguran Terbuka (TPT) menggunakan metode Regresi Linear.
Dataset : Data diperoleh dari Badan Pusat Statistik (BPS) Sulawesi Tengah.
Variabel : 
- X : Tingkat Partisipasi Angkatan Kerja (TPAK)
- Y : Tingkat Pengangguran Terbuka (TPT)
Jumlah Data : 104 data observasi (13 kabupaten/kota × 8 tahun, 2018–2025)
Metode : Linear Regression (Scikit-Learn)
Hasil :
Koefisien regresi: -0.0989
Intercept: 10.0274
R² Score: 0.1274
Kesimpulan: TPAK memiliki hubungan negatif terhadap TPT, namun pengaruhnya relatif rendah karena nilai R² sebesar 12,74%.
